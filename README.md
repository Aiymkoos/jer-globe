# Жер — планета в твоих руках

3D-глобус, которым управляешь руками через обычную веб-камеру. Одной рукой хватаешь и крутишь Землю, другой приближаешь пальцами, как на телефоне, — до улиц своего города. Осуши океаны, подними уровень моря, вернись в ледниковый период, посмотри на ночные огни городов, найди МКС и землетрясения прямо сейчас — и проверь себя в викторине «Найди страну».

**Попробовать:** <https://aiymkoos.github.io/jer-globe/>

**Направление кейса:** свободный вариант — интерактивный глобус с управлением руками.

## Режимы глобуса

| # | Режим | Что видно |
|---|---|---|
| 1 | Спутник | Спутниковые снимки до уровня улиц, границы и названия стран и городов |
| 2 | Без воды | Океаны осушены: подводные хребты, желоба, Марианская впадина — по реальным данным рельефа дна |
| 3 | Растаяли льды | Уровень моря +70 м (если растают все ледники). Уровень меняется ладонью от −130 до +100 м |
| 4 | Ледниковый период | Море на 120 м ниже: песочным — суша 20 тыс. лет назад (мост Азия—Америка, Британия соединена с Европой) |
| 5 | Ночная Земля | Огни городов из космоса, снимки NASA Black Marble |
| 6 | Живая Земля | Землетрясения за сутки (USGS) и МКС в реальном времени — над какой страной она сейчас |
| 7 | Викторина | Найди страну на глобусе и покажи её пальцем |

МКС видна на глобусе во всех режимах и обновляется каждые 5 секунд.

## Жесты

| Жест | Действие |
|---|---|
| Кулак — потянуть | По умолчанию перетаскивание: глобус следует за рукой и останавливается, когда раскрываешь ладонь. Кнопка в окне камеры переключает на джойстик |
| Две раскрытые ладони — развести / свести | Приблизить / отдалить (щипок убран: камера путала его с указателем) |
| Два кулака — развести / свести | Приблизить / отдалить |
| Указательный палец на страну, подержать 0,7 с | Карточка страны: флаг, столица, население, справка из Википедии; в викторине — ответ |
| Палец на кнопку режима, подержать | Выбрать режим |
| Ладонь — взмах вправо / влево | Следующий / предыдущий режим |
| Ладонь вверх / вниз в режимах с морем | Поднять / опустить уровень моря |

Захват «липкий»: если кулак на миг разжался неплотно, глобус не выпадает — отпускает только раскрытая ладонь. Движение руки сглаживается, мелкое дрожание не передаётся глобусу. Руки различаются по положению в кадре и «держат» свою роль, пока видны рядом с прежним местом — поэтому одна рука может крутить, а другая одновременно приближать. Без камеры всё работает мышью: тянуть — крутить, колёсико — масштаб, клик по стране — карточка, цифры 1–7 — режимы, стрелки ↑↓ — уровень моря.

## Режим «ошибка»

| Что не так | Подсказка |
|---|---|
| Кулак сжат неплотно | «Сожми кулак плотнее, чтобы схватить глобус» |
| Слишком резкое вращение | «Крути плавнее — глобус не успевает за рукой» (скорость ограничивается) |
| Кулак у края кадра | «Рука у края кадра — разожми кулак и перехвати глобус ближе к центру» |
| Кулак слишком далеко от центра (джойстик) | «Кулак слишком далеко от центра — глобус и так на полной скорости» |
| Два кулака слишком близко | «Руки слишком близко — разведи их шире, чтобы менять масштаб» |
| Взмах ладонью по диагонали | «Чтобы сменить режим, веди ладонь горизонтально» |
| Короткий взмах | «Продолжи взмах дальше в сторону» |
| Уровень моря за пределами | «Выше +100 м уровень не поднимается», «Ниже −130 м моря не было даже в ледниковый период» |
| Максимальное приближение | «Ближе уже некуда — это максимальное приближение» |
| Викторина: не та страна | «Это Узбекистан. Нужная страна севернее, примерно 900 км — потяни глобус кулаком вниз» (неверная страна подсвечивается красным) |
| Викторина: палец на океане | «Это океан — наведи палец на сушу и подержи» |

Кольцо вокруг указателя показывает, сколько ещё держать палец.

## Собственная логика

- **`js/hands.js`** — две руки → действия: «липкий» захват и вращение со сглаживанием, мёртвой зоной и ограничением скорости, масштаб двумя ладонями или двумя кулаками (логарифмически, с мёртвой зоной), взмахи одной ладонью с защитой от случайных срабатываний, уровень моря, различение рук по положению. Не зависит от камеры и карты, покрыта тестами.
- **`js/gestures.js`** — поза руки по углам сгиба пальцев в 3D, щипок с гистерезисом, подсказки для «почти правильных» поз.
- **`js/quiz.js`** — викторина: направление (8 сторон света) и расстояние по дуге большого круга до нужной страны, подсказка, куда повернуть глобус, очки и серии.
- **`js/live.js`** — МКС и землетрясения; над какой страной станция — проверка «точка в многоугольнике» по границам стран.
- **`js/globe.js`** — стиль глобуса: раскраска рельефа суши и дна для «без воды», затопление по порогу высоты для «потопа» и «ледникового периода».

## Данные (бесплатные, без ключей)

- Спутник: Esri World Imagery · Рельеф суши и дна: Mapzen Terrain Tiles (AWS Open Data)
- Названия: OpenStreetMap через OpenFreeMap · Ночные огни: NASA Black Marble (GIBS)
- Страны, столицы, население: Natural Earth · Флаги: flagcdn · Справки: Википедия
- Землетрясения: USGS · МКС: wheretheiss.at
- Движок глобуса MapLibre GL JS (BSD-3), распознавание рук MediaPipe (Apache-2.0) — лежат в `vendor/`.

## Запуск локально

```bash
git clone https://github.com/Aiymkoos/jer-globe.git
cd jer-globe
python -m http.server 5190
```

Открыть <http://localhost:5190>. Камера работает на `localhost` или по `https`. Нужен интернет для снимков и данных.

## Тесты

```bash
npm install
npm test
```

47 автоматических тестов: геометрия жестов и викторина, остановка при потере руки,
отсутствие рывка при захвате, нулевая дистанция щипка, принадлежность взмаха одной руке,
порог чувствительности, время чтения подсказок, выражения рельефа на всём диапазоне
уровней воды. Интеграционные проверки jsdom: блокировка запуска при ошибке WebGL,
панель управления, карточки, отмена таймера викторины и выбор сквозь панели.

DOM-тесты используют заглушки карты и камеры: они не подтверждают реальный WebGL,
спутниковые тайлы и качество распознавания на устройстве. Перед сдачей нужны проверки
с камерой на ноутбуке: плавное вращение, стоп, три скорости, масштаб, выбор страны,
полное прохождение викторины и все семь режимов.

## Управление и доступность

- «Скорость»: Точно / Обычно / Быстро. Настройка сохраняется в браузере. Обычное
  перетаскивание использует вдвое меньший коэффициент, чем предыдущая версия.
- «Управление» открывает постоянную памятку: сама не закрывается.
- Подсказки показываются минимум 4,5 с, ошибки — 6,5 с; длинные тексты — до 12 с.
  Новое намеренное действие может заменить старую подсказку; поток распознавания — нет.
- Камеру можно выключить и продолжить мышью. Escape закрывает памятку и карточку.
- Для глобуса нужен WebGL2. При его недоступности старт блокируется и объясняет причину.
- Минималистичный стартовый экран без эмодзи; анимации учитывают prefers-reduced-motion.


Отладка без камеры: `?debug&show=drained|flood|iceage|night|live|quiz&card=KZ`.
