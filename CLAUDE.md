# Жер — глобус в руках

3D-глобус (MapLibre GL, проекция globe) с управлением двумя руками через веб-камеру. Чистый HTML/CSS/JS, без сборки.

## Как запускать
- `python -m http.server 5190`, открыть http://localhost:5190
- Тесты: `npm test`
- Отладка: `?debug&show=<режим>&card=KZ`

## Устройство
- `js/hands.js` — жесты двух рук → действия (без DOM, покрыто тестами).
- `js/globe.js` — стиль и режимы глобуса; `js/quiz.js` — викторина; `js/live.js` — МКС и землетрясения.
- `js/main.js` — связывает камеру, руки, глобус и интерфейс.
- Фоновый Edge (headless) не дожидается обработки GeoJSON без сетевой активности — пустые страны на снимке не значит ошибку.
